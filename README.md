# Headroom for Homebrew

[Headroom](https://github.com/DivyanshGolyan/claude-headroom) forecasts Claude quota outages and unused allowance in the macOS menu bar.

```sh
brew install --cask DivyanshGolyan/headroom/headroom
```

Requires macOS 13 or later on Apple Silicon or Intel. Sign into Claude Code, then open Headroom from Applications.

The app is locally signed. If macOS blocks first launch, use System Settings → Privacy & Security → Open Anyway.

To update:

```sh
brew update
brew upgrade --cask DivyanshGolyan/headroom/headroom
```

Tagged Headroom releases update this tap automatically with a versioned download and verified SHA-256 checksum. Source, installation details, and release notes are in the [Headroom repository](https://github.com/DivyanshGolyan/claude-headroom).
